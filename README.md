# FinBridge: SMS банка → приложение «Финансы»

Скрипт для Mac, который сам вносит операции по картам в приложение
**«Финансы — расходы и доходы»** (Money manager). Банк присылает SMS, iPhone
пересылает её на Mac, скрипт записывает операцию в Mac-версию «Финансов», и
приложение синхронизирует её на iPhone. Вводить траты по карте руками больше не нужно.

## Что умеет

- Приорбанк и БелВЭБ поддерживаются сразу. Другой банк можно добавить, Claude поможет.
- Категорию ставит по названию магазина: Grab → «Транспорт», Евроопт → «Продукты» и т. д.
  Если не понял, ставит «Другое» и ❓ в комментарии, чтобы ты проверил.
- При оплате в валюте берёт сумму в рублях, которую банк на самом деле списал (по остатку из SMS).
- Снятие в банкомате записывает как перевод на счёт «Наличные».
- Перевод между своими картами записывает одним переводом, а не расходом и доходом.
- Если нужно, следит ещё за USDT-кошельками в сети TRON (Trust Wallet) и за Bybit.

Всё работает на твоём Mac, данные уходят только в само приложение «Финансы».
Твои настройки (`config.json`), журналы и копии базы в git не попадают (`.gitignore`).

## Что нужно

- **Mac на Apple Silicon** (M1 или новее): только на нём запускается iPhone-версия «Финансов».
- **«Финансы» на Mac** из App Store. Войди в тот же аккаунт, что и на iPhone, и включи синхронизацию.
- **SMS с iPhone приходят на Mac**: iPhone → Настройки → Приложения → Сообщения →
  Переадресация SMS → включи свой Mac (и лучше ещё «Сообщения в iCloud»).
- **Python 3.9+**: проверь командой `python3 --version`. Если Python нет, macOS сама предложит его установить.
- **Claude Code**, чтобы он настроил всё за тебя.

## Как начать

```sh
git clone https://github.com/ANdrew13934/finbridge.git ~/finbridge
cd ~/finbridge
claude
```

Напиши Claude: **«Привет, помоги настроить»**. Он прочитает `CLAUDE.md` и проведёт
по шагам: найдёт твои карты и счета, настроит категории, покажет пробный прогон
(без записи) и включит автозапуск. Займёт минут 20–30. От тебя понадобится пара
галочек в Системных настройках и ответы, какой счёт какой карте соответствует.

## Команды (если без Claude)

| Команда | Что делает |
|---|---|
| `python3 show_ids.py` | счета и категории приложения с их uid (для `config.json`) |
| `python3 bridge.py --list-senders` | от кого есть SMS: так находится имя отправителя банка |
| `python3 check_sms.py` | прогоняет все SMS банка: какие карты нашлись, что не распознано |
| `python3 learn.py` | какие категории ты раньше ставил вручную по каждому магазину |
| `python3 bridge.py --check-config` | проверяет, что все uid в `config.json` есть в приложении |
| `python3 bridge.py --dry-run` | показывает, что было бы добавлено, ничего не меняет |
| `python3 bridge.py --test-tx` | добавляет тестовую операцию 0.01 и проверяет, что она уходит на iPhone |
| `python3 bridge.py --fix-balances --dry-run` | сравнивает балансы в приложении с остатком из SMS |
| `./install.sh` / `./uninstall.sh` | включить / выключить запуск каждые 5 минут |

## Важно

- После момента `start_from` из `config.json` **не вноси вручную операции по подключённым
  картам**: скрипт добавит их сам. Похожие дубли он пропускает, но лучше на это не рассчитывать.
- Записи с ❓ в комментарии стоит проверить и поправить категорию в приложении.
- Перед каждой записью скрипт сохраняет копию базы приложения в `backups/`.
- Скрипт неофициальный: он пишет прямо в базу приложения так же, как это делает
  само приложение. После крупного обновления «Финансов» его, возможно, придётся поправить.
